# Chrome Client's copy of PolyPlus

This is a modified copy of **PolyPlus** by Polyfrost (https://github.com/Polyfrost/PolyPlus), used by Chrome Client.
PolyPlus is licensed under GPL-3.0-only; this copy is under the same license (see LICENSE.md) and all of its source is in this repository.

Changes made here (the original work stays Polyfrost's):
- the OneClient name, logo and loading-screen art are replaced with Chrome Client's
- the marketplace tab, the version label and the "special chat" text in the Social tab are removed
- the wardrobe lists Chrome Client's own cosmetics

Original copyright notices are kept in the source files.
